# XamlDeferLoadStrategy pilot, 2026-09-24

**Eight migrations completed in two separately reported four-arm lanes.**
Every output built and launched independently, but none preserved visible
scenario-navigation labels. This is measured negative pilot evidence, not a
basis for broad keep/shrink/remove claims: there is only one public task family
and one attempt per treatment in each distinct protocol.

The frozen candidate is PR #134 at
`196d076e92d7161031dba5eef50f4e23e04a4d8e`; source is the complete C# sample at
`4eb2fcb499c5bc549e918920cfd2b64396a650d9`, including three pages, linked shared
source and assets. B has the eight common skills without the UWP package;
T adds tools/inventory, L adds compact routing and the unchanged on-demand
catalog, and F uses the full unchanged migration skill.

## Retained infrastructure failures and correction

The first saved four-row schedule, experiment
`94ea2cd8-cfe5-42a9-9ae1-945ce92980e7`, used an unqualified custom-agent name.
Its first T invocation exited 1 before model work; F/L/B stayed `not_run`.
The CLI requires `winui:winui-dev`. That entire schedule is retained in
[the plumbing export](2026-09-24-cli-plumbing.json). Missing usage remains
unknown, not zero.

The first independent T assessment exposed an evaluator error:
WinApp 0.6.1 rejects `--quiet` with `--json`. Known-good scaffold calibration
then exposed a PowerShell PID type-predicate precedence bug and WinApp's
hash-identical `AppX` staging path. These were corrected without editing any
agent output. A separately versioned evaluator assessed **all four** immutable
deliverables uniformly. Original failed assessments and calibration artifacts
remain retained locally; they are infrastructure failures, not evidence that T
failed to launch.

The original UWP app was independently built and exercised: all three pages,
four deferred rectangles, navigation reset, adaptive mail/panes/accounts and
both photographs were observed. A later pure-evidence calibration found that
the photo matcher assumed a centered crop, while the source renders the top-left
crop. Correcting only the crop origin made both actual source photographs pass
the unchanged error threshold of 24 (errors 12.8867 and 12.56); asymmetric
goldens and blank/wrong-photo mutants were added. This does not change the four
constrained outcomes, which all stopped at the earlier navigation gate.

blocks continuation; there is no prompt-only safety fallback.

## Retention, replay and cleanup

An independently hashed local archive retains the experiment/harness snapshots,
immutable source/output, attempts, usage, evaluation records, raw run-owned logs
and screenshots. Its `archive-manifest.json` maps each original root to its
archive-relative root and hashes every retained file. Regenerable `bin`/`obj`,
live workspaces, caches, agent homes, credential/config stores and signing keys
are excluded. Raw records are not rewritten to hide their original paths.
The retained archive contains **2,032 files / 85,499,263 bytes**; its manifest
SHA256 is `d19f0a3fba53426a11d04b2154e82d667b23f657f94e7d9ddc195012d75697dd`.

Public report JSON can be read and summarized anywhere with no model or desktop.
For example, from the repository root:

```powershell
$report = Get-Content .\benchmarks\uwp-skill-value\reports\2026-09-24-owned-runtime.json -Raw | ConvertFrom-Json
$report.rows | Select-Object arm,agent_seconds,ai_credits,native_agent_exit,evaluation_status
$report.summary.ai_credits
```

`report.py`/`runner.py report` replay against the original retained experiment
roots and check frozen-output paths. They are **not relocation-aware**: copied
raw records retain absolute paths. To reproduce that offline report after
temporary roots are removed, restore the corresponding archived roots at their
recorded original locations. Rebuilding/re-running UI evaluation also requires
the pinned Windows toolchain and a separately reserved desktop; an archive
alone does not recreate OS/cache state.

After all eight assessments, ten remaining evaluator/calibration registrations
were removed only after their exact package name/family/full name and recorded
installation directory matched retained evidence. All ten exact names were
verified absent. No unrelated app, shared frame host or framework package was
removed. Per-attempt agent cleanup and final evaluator cleanup are separate
records; cleanup does not delete the retained evidence.
