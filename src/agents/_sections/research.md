
### API Research
Before using any unfamiliar concepts or features, research it via the Microsoft Learn MCP server or web search:
1. **Search docs** — `"<concept or feature> WinUI 3 Windows App SDK C#"` (scoped) and `"<concept or feature> Windows app"` (broad)
2. Search for tutorial and guides, but optimize for those that are relevant to winappsdk and winui - identify out of date content and be sceptical / valdiate usage

**Research gate:** Do NOT start coding until you've confirmed the correct APIs/packages/dependencies. Guessing wastes more time than researching.
